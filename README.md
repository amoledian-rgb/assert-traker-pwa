- **날짜별 저장 기록 10개씩 페이지(2026-11-26 · `asset-shell-v41`)**: 추이 탭 **날짜별 저장 기록**을 최신순 **10개씩** 나눠 보여 줍니다. 기록이 10개 이하면 예전처럼 페이지 바 없이 그대로이고, 11개부터는 목록 아래에 `1 / 3페이지` 안내와 함께 **`‹ 1 2 3 … ›`** 숫자 바가 붙습니다(페이지가 7개를 넘으면 `1 … 6 7 8 … 12` 처럼 지금 페이지 주변만, 390px 폭에 한 줄로 들어갑니다). **목록을 왼쪽으로 밀면 다음 페이지, 오른쪽으로 밀면 이전 페이지**로 넘어가고, 1페이지에서 오른쪽·마지막 페이지에서 왼쪽으로 밀면 그대로 있습니다. 목록 안의 가로 스와이프는 **페이지 이동만** 하고 하단 탭 이동은 발동하지 않으며(`data-no-tab-swipe` + `stopPropagation`), 세로로 밀면 화면 스크롤로 동작합니다. 기록이 지워져 페이지 수가 줄면 지금 페이지를 유효 범위로 자동 보정합니다. 🌐 시장 탭은 건드리지 않았습니다.
- 오프라인에서도 열립니다(Service Worker 캐시).
- **탭 좌우 스와이프(2026-11-24 추가)**: 화면을 **왼쪽으로 밀면 다음 탭, 오른쪽으로 밀면 이전 탭**으로 갑니다(시장 → 요약 → 입력 → 예수금 → 종목 → 추이 → 백업). 세로 스크롤이 우세한 움직임(가로 이동 55px 미만이거나 세로의 1.6배 미만)이나 짧은 움직임은 탭을 바꾸지 않고, **입력 칸·가로 스크롤되는 표·하단 탭바 위에서 시작한 터치**도 건너뜁니다. 첫 탭에서 오른쪽, 마지막 탭에서 왼쪽으로 밀면 그대로 있습니다.
