# 내 자산관리 (PWA)

폰 홈 화면에 설치해 쓰는 개인 자산 기록 앱입니다. 서버 없이 브라우저 안에서만 동작합니다.

- **개인 데이터 없음**: 이 저장소의 앱은 빈 껍데기입니다. 계좌 이름 틀과 0원짜리 빈 상태만 들어 있습니다.
- 사용자가 **💾 백업 → 불러오기**로 넣은 데이터는 그 폰의 브라우저 저장소(localStorage)에만 남고, 어떤 서버로도 전송되지 않습니다.
- 하단 탭은 **시장 · 요약 · 원화 · 달러 · 종목 · 비중 · 추이 · 백업** 8개입니다. 앱을 열면 첫 화면이 **🌐 시장** 탭입니다.
  - **시장 탭**: 시장종합(주식일기 시트 왼쪽 항목) — 국내 지수(코스피·코스닥 지수/전일비/등락률/거래대금), 고객예탁금·신용잔고와 프로그램 차익·비차익, 투자자별 매매동향(개인·외인·기관 × 코스피/코스닥/선물/주식선물), 국채수익률(한국·일본·미국 10년/2년), 시장지표(달러인덱스·VIX·VKOSPI·금), 유가(WTI·브렌트), 비트코인(BTC/USDT), 환율(USDKRW·USDJPY). 앱을 열 때와 **🔄 새로고침** 때 `market.json` 을 새로 받고, 환율·USDJPY·비트코인은 브라우저에서 공개 API(마나나·exchangerate-api·업비트→코인게코)로 즉시 다시 받습니다. 받지 못한 값은 지어내지 않고 `—` + 미제공으로 둡니다(VKOSPI 는 공개 시세가 없어 계속 —).
  - **요약 탭**: 전체 자산·손익, 일반/연금 계좌 비교, 계좌별 금액.
  - **원화 탭**: 기준일 · 원화자산 요약, 원화(KRW) 보유 종목, 계좌별 투자원금(예치금)·원화 예수금, 계좌 추가·이름/구분 수정·삭제.
  - **달러 탭**: 현재 환율·기준(매입) 환율, 달러자산 요약(달러 주식·달러 예수금·합계 및 원화 환산·예상 환차익), 달러(USD) 보유 종목, 계좌별 달러 예수금(소수점 넷째 자리까지).
  - **비중 탭**: 전체자산 대비 주식·예수금 비중 요약과 종목별 보유비중(%)·막대, 예수금 비중 참고 행(합계 100.0%).
  - **추이 탭**: 자산총액 그래프(**일 · 주 · 월 · 년**)와 기간 변동액·변동률·최고/최저/최근 값, 그래프 아래 **날짜별 저장 기록**(자산총액·전일 대비 증감·`불러오기`). 그래프는 외부 라이브러리 없는 SVG이고, 점을 누르면 그날 날짜와 자산총액이 툴팁으로 나옵니다.
- 달러(USD) 현재가·매입단가·수량·달러 예수금은 **소수점 넷째 자리까지** 넣고 표시합니다($500.00 ~ $123.4567).
- **환차익 자동 계산**: 달러 탭의 **기준(매입) 환율**을 넣으면 `환차익 +594,724원 (달러당 +36.50원)`처럼 표시합니다(현재 환율 − 기준 환율) × 달러자산. 비워 두면 계산하지 않습니다.
- **수동 저장**: 원화·달러 탭에서 고친 값은 화면(메모리)에만 반영되고, 아래 **💾 저장하기**를 눌렀을 때만 이 폰에 저장됩니다. 두 입력 탭에서는 저장 바가 늘 보이고, 다른 탭에서는 저장 안 된 변경이 있을 때만 주황색으로 나타납니다. **↩️ 되돌리기**로 마지막 저장 상태로 바로 돌아갈 수 있습니다.
- **종목명 또는 티커로 현재가 자동 조회**: 종목 카드에 **종목명**과 **티커**(예: `005930`, `NVDA`) 칸이 있고, 둘 중 하나만 적어도 `prices.json` 에서 찾아 현재가를 채웁니다(종목명 칸에 티커를 적어도 인식). 이름·티커·현재가가 비어 있으면 서로 보완합니다.
- **저장할 때 현재가 자동 채움**: 종목명(또는 티커)과 수량만 넣고 **💾 저장하기**를 누르면 `prices.json` 을 새로 받아(`cache: 'no-store'`) 현재가를 채운 뒤 저장합니다. 시세 목록에 없는 종목은 현재가를 0으로 저장하고 카드와 안내 문구로 알려 줍니다(없는 값을 지어내지 않습니다). 새 종목을 쓰려면 써니에게 종목명·티커를 알려 주세요 — `watchlist.json` 에 추가하면 다음 갱신부터 채워집니다.
- **종가 자동 반영**: 앱을 열 때 `prices.json`(종목명·종목코드·현재가·환율만 담긴 파일)을 조용히 읽어, 새 시세가 있으면 종목 현재가와 환율·기준일을 자동으로 채웁니다. 자동 반영은 '저장 안 된 변경'으로 잡히지 않고, **🔄 종가 새로고침** 버튼(원화·달러 탭 상단)으로 언제든 다시 불러올 수 있습니다. 오프라인이거나 파일이 없으면 그냥 넘어갑니다.
- **실시간 원/달러 환율**: 앱을 열 때와 **🔄 종가 새로고침** 때 공개 환율 API 에서 원/달러 환율을 받아 현재 환율에 반영합니다(1순위 국내 시세 `api.manana.kr` → 2순위 `open.er-api.com` → 3순위 `currency-api`(jsDelivr)). 달러 탭 환율 칸 아래에 `🟢 실시간 환율 반영 1,344.20원 · 국내 시세 11/24 16:00 기준`처럼 출처와 시각이 남습니다. 모두 실패하거나 오프라인이면 `prices.json` 의 환율을 그대로 쓰고, 과거 기록(📅 조회 중)의 환율은 덮어쓰지 않습니다. 개인 데이터는 보내지 않는 공개 GET 한 번뿐입니다.
- 종목 카드·계좌 카드 사이를 **진한 구분선**으로 나눠 경계가 한눈에 보입니다.
- **날짜별 기록(스냅샷)**: `💾 저장하기`를 누르면 그 평가 기준일의 계좌·수량·가격·예수금·환율·총자산이 이 폰에 날짜별로 남습니다. 20:10 이후 종가가 반영될 때도 그날 기록이 자동으로 쌓이고, 며칠 앱을 열지 않아도 `prices_history.json` 의 날짜를 마지막 저장된 수량 기준으로 메웁니다. **추이 → 불러오기**로 과거 날짜를 그대로 볼 수 있고, 그동안은 상단에 `📅 2026-11-16 기록 조회 중` 배너가 뜨며 입력은 잠깁니다(최신으로 돌아가기 버튼으로 복귀). 기록은 백업 파일에도 함께 담깁니다.
- 오프라인에서도 열립니다(Service Worker 캐시).

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 본체 (시장 / 요약 / 원화 / 달러 / 종목 / 비중 / 추이 / 백업) |
| `market.json` | 시장종합 수치(지수·예탁금/신용·프로그램·투자자별·국채·지표·유가·BTC·환율) — `fetch_market.py` 가 네이버 증권·업비트에서 받아 만든다. 금액·계좌 정보는 없습니다. |
| `prices.json` | 종목별 현재가(마감 뒤에는 종가)와 원/달러 환율 — 네이버 증권에서 받아 만든 시세 파일(국내 12종목 + 미국 5종목). 수량·금액·계좌 정보는 없습니다. |
| `prices_history.json` | 날짜별(`YYYY-MM-DD`) 종목가·환율 기록. 추이 그래프와 빠진 날짜 보충에 씁니다. 첫 기록 2026-11-16. |
| `manifest.json` | 설치형 앱 설정 |
| `sw.js` | 오프라인 캐시 (현재 `asset-shell-v14`) — `prices.json`·`prices_history.json`·`market.json` 은 네트워크 우선 |
| `icon-192.png`, `icon-512.png`, `icon-180.png` | 앱 아이콘 |
| `tools/make_icons.py` | 아이콘 생성 스크립트 |
