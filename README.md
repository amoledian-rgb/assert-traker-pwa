# 내 자산관리 (PWA)

폰 홈 화면에 설치해 쓰는 개인 자산 기록 앱입니다. 서버 없이 브라우저 안에서만 동작합니다.

- **개인 데이터 없음**: 이 저장소의 앱은 빈 껍데기입니다. 계좌 이름 틀과 0원짜리 빈 상태만 들어 있습니다.
- 사용자가 **💾 백업 → 불러오기**로 넣은 데이터는 그 폰의 브라우저 저장소(localStorage)에만 남고, 어떤 서버로도 전송되지 않습니다.
- 하단 탭은 **요약 · 원화 · 달러 · 종목 · 비중 · 백업** 6개입니다.
  - **원화 탭**: 기준일 · 원화자산 요약, 원화(KRW) 보유 종목, 계좌별 투자원금(예치금)·원화 예수금, 계좌 추가·이름/구분 수정·삭제.
  - **달러 탭**: 현재 환율·기준(매입) 환율, 달러자산 요약(달러 주식·달러 예수금·합계 및 원화 환산·예상 환차익), 달러(USD) 보유 종목, 계좌별 달러 예수금(소수점 넷째 자리까지).
  - **비중 탭**: 전체자산 대비 주식·예수금 비중 요약과 종목별 보유비중(%)·막대, 예수금 비중 참고 행(합계 100.0%).
- 달러(USD) 현재가·매입단가·수량·달러 예수금은 **소수점 넷째 자리까지** 넣고 표시합니다($500.00 ~ $123.4567).
- **환차익 자동 계산**: 달러 탭의 **기준(매입) 환율**을 넣으면 `환차익 +594,724원 (달러당 +36.50원)`처럼 표시합니다(현재 환율 − 기준 환율) × 달러자산. 비워 두면 계산하지 않습니다.
- **수동 저장**: 원화·달러 탭에서 고친 값은 화면(메모리)에만 반영되고, 아래 **💾 저장하기**를 눌렀을 때만 이 폰에 저장됩니다. 두 입력 탭에서는 저장 바가 늘 보이고, 다른 탭에서는 저장 안 된 변경이 있을 때만 주황색으로 나타납니다. **↩️ 되돌리기**로 마지막 저장 상태로 바로 돌아갈 수 있습니다.
- 종목 카드·계좌 카드 사이를 **진한 구분선**으로 나눠 경계가 한눈에 보입니다.
- 오프라인에서도 열립니다(Service Worker 캐시).
