# 내 자산관리 (PWA)

폰 홈 화면에 설치해 쓰는 개인 자산 기록 앱입니다. 서버 없이 브라우저 안에서만 동작합니다.

- **개인 데이터 없음**: 이 저장소의 앱은 빈 껍데기입니다. 계좌 이름 틀과 0원짜리 빈 상태만 들어 있습니다.
- 사용자가 **💾 백업 → 불러오기**로 넣은 데이터는 그 폰의 브라우저 저장소(localStorage)에만 남고, 어떤 서버로도 전송되지 않습니다.
- 계좌는 앱 안에서 직접 **추가 · 이름/구분 수정 · 삭제**할 수 있습니다(삭제 시 그 계좌의 종목도 함께 삭제 안내).
- 오프라인에서도 열립니다(Service Worker 캐시).

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 본체 (요약 / 입력 / 종목 / 백업) |
| `manifest.json` | 설치형 앱 설정 |
| `sw.js` | 오프라인 캐시 (현재 `asset-shell-v4`) |
| `icon-192.png`, `icon-512.png`, `icon-180.png` | 앱 아이콘 |
| `tools/make_icons.py` | 아이콘 생성 스크립트 |

GitHub Pages 로 배포됩니다.
